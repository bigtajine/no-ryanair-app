# Chrome extension

To install, open `chrome://extensions`, turn on Developer mode, click Load unpacked, and select this folder.

Open [ryanair.com](https://www.ryanair.com) Manage Trip while logged in and click the toolbar icon. The extension refreshes your web session token, calls `mntappbp.ryanair.com`, and downloads an Aztec PNG of your boarding pass.

It uses your existing login only. The disclaimer in the root `README.md` applies.
